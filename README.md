## What It Does
This Python program calculates the total resistance of resistors connected in series and parallel. It accepts multiple resistor values and displays the calculated results in ohms.

## How to Run It
1. Install Python 3.
2. Open a Python IDE.
3. Copy the Python code.
4. Save as resistor_calculator.py.
5. Run the program.

## Sample Output
Resistors entered: [10.0, 20.0, 30.0]

Series resistance: 60.0 ohms
Parallel resistance: 5.45 ohms

Difference: 54.55 ohms

## My Own Twist
